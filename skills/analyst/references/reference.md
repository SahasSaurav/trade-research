# Analyst reference

## Rating mapping table

Read the rating from the report **body**, not the headline. Headline language may be informal.

| Report language                                        | Standardized rating |
| ------------------------------------------------------ | ------------------- |
| Positive, Overweight, Outperform, Accumulate, Buy      | **Buy**             |
| Equal-weight, Inline, Perform, Market Perform, Neutral | **Hold**            |
| Reduce, Underperform, Underweight, Sell                | **Sell**            |

**Mapping examples:**

- "We rate the stock Overweight" → **Buy**
- "We initiate with Market Perform" → **Hold**
- "Downgrade to Underweight" → **Sell**
- Headline says "upgrade" but body says "Neutral" → **Hold** (body wins)

## Firm tier hierarchy

### Tier 1 — Primary sources (3+ firms here = sufficient coverage)

**Investment banks:** Goldman Sachs, Morgan Stanley, J.P. Morgan, UBS, Barclays, Deutsche Bank, Bank of America, Citigroup, Wells Fargo, Jefferies

**Independent research:** Bernstein, ISI (Evercore ISI), MoffettNathanson, Oppenheimer, Raymond James, Cowen, Needham, Stifel

**How to find:** Search "[firm name] [ticker] rating" or visit the firm's research page directly.

### Tier 2 — Aggregators (use only if Tier 1 yields <3)

- **TipRanks, MarketBeat** — aggregators; verify each rating links to the original firm's research
- **Zacks, StockAnalysis.com** — rating aggregators; cross-reference to original firm
- **Seeking Alpha** — include only if a named Tier 1 or Tier 2 analyst is explicitly credited
- **Benzinga** — financial news; use only named analyst reports

**Stop searching:** After exhausting Tier 1 and finding at least 1 credible report, you have done due diligence. Return what you verified.

## Source priority and recency

### Source hierarchy (best to acceptable)

1. **Firm's own research page** — official research site or press release
2. **Company press release** — if the firm issued a public note
3. **Bloomberg, Reuters, CNBC** — major outlets citing the research with clear source attribution
4. **TipRanks, MarketBeat** — aggregators linking to the original
5. **Seeking Alpha** (named analyst only)

**Do NOT use:** Blogs, speculation ("analysts may be"), secondhand paraphrase, or personal investment sites.

### Recency standard

| Age          | Status                                              |
| ------------ | --------------------------------------------------- |
| Last 30 days | **Preferred**                                       |
| 31–90 days   | **Acceptable**                                      |
| >90 days     | **Stale** — exclude unless no fresher sources exist |
